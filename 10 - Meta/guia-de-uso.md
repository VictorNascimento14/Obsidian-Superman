# Guia de uso do cofre

1. Clone o cofre e abra a pasta no Obsidian.
2. Antes de escrever, veja a tabela "Se mudou X, documente em Y" no `CLAUDE.md` da raiz.
3. Use os modelos de `09 - Templates`.
4. Um commit do cofre por PR do jogo: nota do PR + changelog + nota do sistema.
