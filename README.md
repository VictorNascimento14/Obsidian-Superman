# Obsidian-Superman

Cofre de documentação do jogo **Superman — Metropolis Flight**
([VictorNascimento14/Superman](https://github.com/VictorNascimento14/Superman)).

Abra esta pasta como cofre no Obsidian. O ponto de partida é
[[visao-de-produto]] e, para o estado das coisas, [[roadmap]] e [[2026]] (changelog).

| Pasta | O que guarda |
|---|---|
| `00 - Índice` | MOCs: visão, roadmap, arquitetura, ledger de ADRs, aprendizados |
| `01 - PRs` | Uma nota por PR mergeado |
| `02 - ADRs` | Decisões arquiteturais numeradas |
| `03 - Changelog` | Linha do tempo por ano (Keep a Changelog) |
| `04 - Aprendizados` | Bugs instrutivos e armadilhas |
| `05 - Gameplay` | Mecânicas: voo, poderes, missões, controles |
| `06 - Render` | Pipeline gráfico: renderer, céu, luz, pós-processamento |
| `07 - Mundo` | Cidade procedural, colisão, tráfego |
| `08 - Infra e Deploy` | Build, CI, GitHub Pages, runbooks |
| `09 - Templates` | Modelos de nota |
| `10 - Meta` | Como usar e manter o cofre |
