# PR #1 — Fundação: Vite, Three.js, CI e convenções

## 🎯 Contexto

Primeiro PR do jogo. Antes de qualquer sistema, o repositório precisa de build,
teste, CI e das regras de trabalho — as mesmas do Processual, adaptadas.

## 🔧 Mudanças

- `package.json` — Three.js 0.186, postprocessing 6.39, Vite 8; `npm test` usa `node --test`.
- `vite.config.js` — `base: './'` para o mesmo build servir no Pages.
- `src/core/rng.js` — mulberry32 com semente; toda a cidade vai sair dele.
- `src/main.js` — sobe o `WebGLRenderer` e o loop; o resto entra PR a PR.
- `CLAUDE.md` — adaptado do Processual: REGRA #0 do cofre (`$SUPERMAN_VAULT`),
  "NUNCA faça", fluxo de publicar, zero assinatura de IA, seção 📓 obrigatória.
- `PROJETOS.md` — registro do kit-mcp (pasta, repo, cofre).
- `.github/workflows/ci.yml` — `npm ci`, `npm test`, `npm run build`.
- `.github/workflows/pr-documentacao.yml` — reprova PR sem `## 📓 Documentação`
  linkando o cofre.

## 🧠 Decisões técnicas

- **`node --test` em vez de Vitest**: a stdlib cobre o que precisamos (lógica pura);
  uma dependência a menos. Ver [[build-e-ci]].
- **Sem ESLint por ora**: o build do Vite já pega erro de sintaxe e import quebrado.
  Entra se o código crescer a ponto de pedir.

## 🧪 Como testar

1. `npm install && npm test && npm run build`
2. `npm run dev` → tela azul-escura (o renderer vivo).
